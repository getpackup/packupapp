# Dev Commands

| Task                                                                | Command          |
| ------------------------------------------------------------------- | ---------------- |
| Development server (<http://localhost:5173>[http://localhost:5173]) | `pnpm dev`       |
| Production build                                                    | `pnpm build`     |
| Type checking (React Router typegen + tsc)                          | `pnpm typecheck` |
| Lint                                                                | `pnpm lint`      |
| Lint + auto-fix                                                     | `pnpm lint:fix`  |
| Tests (vitest, jsdom)                                               | `pnpm test`      |
